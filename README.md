# 🎵 صانع الإيقاعات التعليمي

أداة تعليمية تفاعلية تسمح للمستخدم بإنشاء إيقاعات موسيقية بسهولة باستخدام واجهة بسيطة ومباشرة. تم بناء المشروع باستخدام HTML وCSS وJavaScript مع إمكانية استخدام مكتبات صوت مثل **Tone.js**.

---

## 🚀 الخصائص

* إنشاء إيقاعات موسيقية بطريقة مرئية.
* مصفوفة خطوات (Step Sequencer) تصلح للتعليم والتجريب.
* التحكم في سرعة الإيقاع (BPM).
* إمكانية اختيار أصوات مختلفة: Kick، Snare، Hi‑Hat.
* يعمل مباشرة على المتصفح بدون تثبيت.

---

## 🧩 التقنيات المستخدمة

* **HTML5** لبناء الهيكل.
* **CSS3** للتصميم.
* **JavaScript** للمنطق التفاعلي.
* **Tone.js** لمعالجة الصوت وإنشاء الإيقاعات.

## 🛠️ كيفية التشغيل محليًا

1. قم بتحميل المشروع أو نسخه:

   ```bash
   git clone https://github.com/USERNAME/REPO.git
   ```

2. افتح الملف:

   ```
   index.html
   ```

3. سيتم تشغيل الموقع مباشرة على المتصفح.

---

## 🌐 النشر على Netlify

1. سجّل الدخول إلى Netlify.
2. اختر **New site from Git**.
3. اربط حساب GitHub.
4. اختر المستودع الذي يحتوي المشروع.
5. سيتم نشر الموقع تلقائيًا.
